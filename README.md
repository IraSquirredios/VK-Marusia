# VK Маруся

Финальная работа курса React.js — адаптивная платформа для поиска фильмов, просмотра жанров и трейлеров, а также ведения списка избранного.

## Возможности

- случайный фильм и топ-10 на главной странице;
- поиск по названию;
- каталог жанров и постраничная подгрузка фильмов;
- подробная страница фильма и просмотр трейлера;
- регистрация и вход с серверной сессией;
- добавление и удаление фильмов из избранного;
- профиль пользователя;
- адаптивная версия для телефона, планшета и компьютера.

## Запуск

```bash
pnpm install
pnpm dev
```

Для производственной сборки:

```bash
pnpm build
pnpm preview
```

Приложение использует API `https://cinemaguide.skillbox.cc` и отправляет запросы авторизации с cookie (`credentials: include`).
